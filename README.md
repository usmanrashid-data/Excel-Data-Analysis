# Excel Data Analysis Projects

This repository contains practical Excel data analysis work completed during the LeepTalent Data Bootcamp. 

## 📁 Key Files & Projects
* **retail_sales_dataset.xlsx / Bike Sales Labs:** Exploratory data analysis, sales performance tracking, and pivot table dashboards.

* **Biggest Atlantic Hurricanes.xlsx:** Historical data cleaning and pattern analysis.

* Pivot Tables & Pivot Charts
* VLOOKUP / XLOOKUP & Conditional Formatting
* Summary Metrics & Dynamic Dashboards
